# 게임 유저 이탈 분석 프로젝트

## 1. 배경 및 문제 정의
- 신규 유저 유입보다 기존 유저 이탈 방지가 게임 매출에 더 큰 영향을 미침
- 어떤 유저가 이탈할 가능성이 높은지 사전에 파악하면
  타겟 리텐션 캠페인 설계 가능
- 분석 대상: Online Gaming Behavior Dataset (40,034명)
- 이탈 정의: EngagementLevel = 'Low' 인 유저 (전체의 약 25.8%)

## 2. 분석 목표
- 이탈 유저와 잔존 유저의 행동 패턴 차이 파악
- 이탈에 영향을 미치는 핵심 변수 도출
- 이탈 위험 유저 세그먼트 정의 및 액션 아이템 제안

## 3. 분석 가설
- 가설 1: 플레이 시간이 짧은 유저일수록 이탈률이 높을 것이다
           → PlayTimeHours 구간별 이탈률 비교
- 가설 2: 결제 경험이 없는 유저가 이탈률이 높을 것이다
           → InGamePurchases 기준 이탈률 비교
- 가설 3: 주간 세션 수가 적은 유저일수록 이탈 가능성이 높을 것이다
           → SessionsPerWeek 구간별 이탈률 비교
- 가설 4: 레벨이 낮은 구간에서 이탈이 집중될 것이다
           → PlayerLevel 구간별 이탈률 퍼널 분석
- 가설 5: RPG 장르 유저가 타 장르 대비 이탈률이 낮을 것이다
           → GameGenre별 이탈률 비교
- 가설 6: 게임 난이도가 높을수록 이탈률이 높을 것이다
           → GameDifficulty별 이탈률 비교
- 가설 7: 세션당 플레이 시간이 짧고 접속 빈도도 낮은 유저가
           이탈률이 가장 높을 것이다
           → SessionsPerWeek + AvgSessionDurationMinutes 조합 분석

## 4. 분석 방법
- EDA: 이탈/잔존 유저 기술통계 비교
- 퍼널 분석: 레벨 구간별 이탈률
- 세그먼트 분석: 플레이 시간·결제 여부·세션 수 기준 그룹화
- 로지스틱 회귀: 이탈 예측 변수 중요도 도출

## 5. 기대 결과 및 활용
- 이탈 위험 유저 조기 식별 기준 정의
- 리텐션 캠페인 타겟 세그먼트 제안
- 게임 내 어느 구간 개선이 이탈 감소에 효과적인지 제안
